# Stack Pact Support

Support for **Stack Pact: Co-op Blocks** and **Stack Pact: 方块同盟** is available by email at **zhaoxiaojian@hotmail.com**.

Stack Pact version 1.0 supports iOS and iPadOS 16 or later.

## Common questions

### Game Center matchmaking does not complete

- Confirm that every player is signed in to a different Game Center account.
- Confirm that every device selected the same 2-player or 3-player match size.
- Cancel the unfinished match and try again. If a Wi-Fi network blocks peer connectivity, trying a different network path can help.

### A nearby game cannot be found

- Allow **Local Network** access for Stack Pact in iOS Settings.
- For the most reliable discovery, connect every device to the same Wi-Fi network and keep this screen open.
- Cancel on every device, switch which device hosts the game, and try again.
- Networks with client or device isolation may prevent nearby devices from discovering or connecting to one another.

### The 3D board is slow on an older device

Open Settings and select **2D Performance** under Presentation Style. It uses the same game rules with a lower-overhead board renderer.

### I need clearer ownership cues or less motion

Open Settings to enable **Distinct Player Markers** or **Reduce Gameplay Motion**. Stack Pact also exposes accessible board actions for assistive technologies.

## 常见问题

### Game Center 匹配一直无法完成

- 确认每位玩家使用不同的 Game Center 账户登录。
- 确认每台设备选择了相同的 2 人或 3 人比赛人数。
- 取消尚未完成的匹配后重试。如果 Wi-Fi 网络阻止设备间连接，可以尝试其他网络路径。

### 找不到附近游戏

- 在 iOS“设置”中允许 Stack Pact 访问“本地网络”。
- 为获得最可靠的发现体验，请将所有设备连接到同一 Wi-Fi，并保持当前页面开启。
- 在所有设备上取消，交换创建游戏的设备，然后重试。
- 启用了客户端隔离或设备隔离的网络可能阻止附近设备相互发现或连接。

### 旧设备上的 3D 棋盘运行较慢

打开“设置”，在“画面风格”中选择“2D 性能”。它采用相同的游戏规则，但棋盘渲染开销更低。

### 我需要更清晰的玩家归属提示或更少的动态效果

打开“设置”，启用“区分玩家标记”或“减少游戏动态效果”。Stack Pact 还为辅助技术提供可访问的棋盘操作。
